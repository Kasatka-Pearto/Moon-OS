# 🌙 Moon OS
Moon OS - is a lightweight console-based operating system written in C++.

Moon OS is a personal C++ project, designed to simulate the real work of OS through terminal. The project focuses on applications management, system commands and object-orientated programming!

## ⭐ Features
- 🔄️ Boot system - simulated operating system startup.
- 💻 System Information — displays basic system information.
- 🧮 Calculator — performs basic mathematical operations.
- 📝 Notepad — reads and writes text files.
- ⚙️ Command System — interactive command-line interface.
- 📦 Application Manager — launches built-in applications.
## 🛠️ Built With

- iostream

## 📜 Available commands
| **Commands** | **Description** |
|:------------:|:---------------:|
| `help` | Displays list of commands |
| `systeminfo` | Shows system info |
| `exit` | Shut downs Moon OS |
| `calc` | Launches calculator app |
| `notepad` | Launches notepad app |
| `clock` | Displays local time |
| `calendar` | Displays date |
| `ls`       | Lists files and directories in the current directory |
| `cd`       | Changes the current directory to the specified path |
| `pwd`      | Shows the current directory |
| `touch`    | Creates a file |
| `rm`       | Removes a file |
| `cat`      | Reads the text in a file |
| `mkdir`    | Creates a directory |
| `rmdir`    | Removes a directory |

## 🚀 Getting Started

### Requirements

- Windows
- C++ compiler (MSVC, MinGW or compatible)
- C++11 or newer

### Compilation

Compile the source file using your preferred C++ compiler.

Example with MSVC:

```powershell
cl /EHsc MoonOS.cpp /Fe:MoonOS.exe
```

### Running

```powershell
MoonOS.exe
```
